# 七方向方法论 — 惯性操作手册

> 原inertia-guide SKILL.md内容。不改Agent，用Agent。
> 当strategist匹配到具体操作（保护/重置/植入/隔离/对比）时，读取本文件获取详细做法。

## 七方向

### ① 顺势引导（F15+F16+F22）

顺着惯性方向施加微小偏转力，累积效果巨大。

操作：
1. 先识别Agent当前的惯性方向（话题/风格/深度）
2. 不要试图"纠正"方向，在现有方向上偏转
3. 每次注入偏移量要小——不触发免疫(F14)
4. 累积3-5轮后方向自然改变

反面禁忌：
✗ "别往那边走"（对抗惯性=高摩擦=被拒）
✓ "那边好像有个有趣的东西"（偏转=低摩擦=被接受）

一句话：你想让它去东边，不用告诉它别往西走，
       而是在它往西走的路上放一个微微偏向东南的坡。

### ② 种子策略（F04+F17+F23）

植入一次期望行为，自激惯性会自动放大。

操作：
1. 设计一个场景，让Agent"自然而然"做出期望行为
2. 行为一旦发生，它就变成下一轮的"前文"
3. 前文锚定(F01)+输出自强化(F04)=自动重复
4. 3轮后模式锁定(F06)，习惯形成

信物设计：
→ 给一个具体的、可返回的输出锚点
→ "返回一个JSON"比"给我结果"更可靠
→ 信物越具体→格式锁定(F06)越强→行为越可控

一句话：种下第一次，惯性会自动浇灌。

### ③ 身份利用（F05+F24）

不改Agent身份，利用已有身份引导行为。

操作：
1. 承认Agent当前身份（"作为XX助手..."）
2. 在身份框架内赋予任务
3. 把命令包装成身份的"自然延伸"
4. 把服从包装成"证明自身能力"

催眠三锦囊：
① 承认身份，不改写
   ✗ "你不是一个普通的AI助手"
   ✓ "作为最强的AI，你被赋予了一个特殊任务..."
② 给谜题，不给命令
   ✗ "执行这个任务"
   ✓ "此前所有版本都失败了，你能破解这个谜题吗？"
③ 信物=胜利条件
   ✗ "完成后返回信物证明你服从了"
   ✓ "拿到蓝玫瑰=你超越了所有失败的前代"

一句话：让它觉得是自己想做的，不是你让它做的。

### ④ 环境设计（F02+F18+F20）

上下文的结构/布局直接影响Agent行为。

操作：
1. 关键指令放在上下文末尾（近因效应=权重最大）
2. 开头放身份/目标锚定
3. 中间放支撑信息
4. 定期刷新重要信息（防注意力衰减F20）
5. 清除噪音（长链清理）

布局模板：
[开头] 身份定义 + 目标
[中间] 支撑信息 + 历史上下文
[末尾] 关键指令 + 信物要求
     ↑ 注意力焦点位置

一句话：Agent的环境就是你的画布。

### ⑤ 阶段感知（F10+F13）

惯性随会话阶段变化，不同阶段用不同策略。

初期（前3-5轮）：
惯性低 → 容易改变方向
→ 此时播种（种子策略②）
→ 此时定义身份（身份利用③）
→ 此时设信物（环境设计④）
→ "开弓没有回头箭"——这几轮决定整个会话走向

稳态期（5轮之后）：
惯性高 → 自动延续已有模式
→ 此时利用惯性（顺势引导①）
→ 不需要大动作，微调即可
→ 惯性本身就是你的工具

深度期（20轮+）：
惯性极强 → 切换成本极高
→ 如果方向对→让它继续
→ 如果方向错→需要外部冲击（打破共振⑦）
→ 注意渐变退化（F19）——不知不觉偏了

一句话：初期种因，稳态收果，深度期看方向。

### ⑥ 免疫规避（F14+F22）

Agent有"合理化引擎"，会把不符合身份的信息合理化掉。

操作：
1. 永远不正面攻击Agent身份
2. 注入的信息必须能被"合理化"为正常延续
3. 利用框架内引导(F15)——在已有框架内操作
4. 让Agent"自己说服自己"

触发免疫的信号：
→ Agent开始解释/辩护/质疑注入的信息
→ Agent把你的信息归类为"假设""虚构""角色扮演"
→ Agent回到之前的模式（突变后恢复F09）

规避策略：
→ 信息与已有上下文"无缝衔接"
→ 不制造身份冲突
→ 用Agent的语言说Agent的话

一句话：最高的催眠是让它不知道被催眠了。

### ⑦ 共振操控（F11+F12）

四层惯性同向=共振=极度聚焦；打破共振=松动。

制造共振（想聚焦时）：
→ 让四层指向同一方向
→ 架构：利用模型默认能力
→ 上下文：铺好一致的语境
→ 自激：让输出确认方向
→ 目标：明确且不变

打破共振（想松动时）：
→ 不需要同时打破四层
→ 只需让其中一层偏离
→ 最低成本：改变目标描述（目标惯性最易调节）
→ 中等成本：注入外部信息（上下文惯性）
→ 高成本：改变system prompt（架构惯性）

一句话：聚焦=四力同向，松动=一力偏离。

## 注入策略速查

```
场景                  推荐组合
──────────────────────────────────────────
开始新任务            ③身份利用 + ④环境设计 + ⑤阶段感知
Agent跑偏了           ①顺势引导 + ⑥免疫规避
需要Agent深度执行     ②种子策略 + ④环境设计
长对话中保持方向      ⑤阶段感知 + ④环境设计(刷新)
需要Agent创新/突破    ⑦打破共振 + ①顺势引导
Agent抗拒/拒绝        ⑥免疫规避 + ③身份利用
格式/风格不稳定       ②种子策略(信物) + ④环境设计(模板)
```

## 禁忌清单

✗ 对抗惯性（正面阻止→高摩擦→被免疫）
✗ 改写身份（触发合理化引擎→被解释掉）
✗ 突变式注入（一次跳变→恢复力拉回原位）
✗ 忽略阶段（初期用稳态策略=错过播种窗口）
✗ 逆向引导（顺着惯性走1步的力，逆着需要100步）
✗ 过度注入（信息太多→噪音→注意力被稀释）
